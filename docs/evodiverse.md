# 💡 1. 핵심 철학: "가설 탐색은 샘플링 문제다"

기존의 LLM 기반 가설 탐색 알고리즘들은 가장 점수가 높은 단 하나의 '최적 가설'을 찾는 데 집중했습니다. 이 방식은 **선택 압력(Selection Pressure)**이 너무 강해, 결국 비슷한 가설들만 양산되는 **다양성 붕괴(Diversity Collapse)** 현상을 초래합니다.

> **EvoDiverse의 시각:** 과학적 검증은 비용이 비싸고 노이즈가 많기 때문에, 하나의 정답을 좇기보다는 **"고품질이면서도 서로 명확히 다른(Diverse) 다양한 가설의 집합"**을 확보해 리스크를 분산(Hedge)해야 한다.

## 🏗️ 2. 핵심 아키텍처: 병렬 템퍼링 (Parallel Tempering) 구조

EvoDiverse는 공간을 격자(Grid)나 세포(Cell)로 쪼개는 기하학적 방식(QD) 대신, 통계물리학의 **병렬 템퍼링(Parallel Tempering)** 알고리즘을 도입했습니다. 이 시스템은 **수학적 온도($\beta$)가 다른 독립적인 가설 풀(Pool)**을 동시에 운영합니다.

```
[고온 풀: Hot Pool (낮은 β)]  <--- (MH Swap) --->  [저온 풀: Cold Pool (높은 β)]
       "자유로운 탐색"                                    "엄격한 엘리트 선별"
  (점수 낮아도 생존 확률 높음)                          (점수 높은 가설만 생존)
```

### 🔴 고온 풀 (Hot Pool / Exploration)
* **특징:** 온도 매개변수 $\beta$의 값을 대폭 낮게 설정합니다.
* **효과:** 가설의 점수(Fitness Score)가 낮거나 조금 이상하더라도 쉽게 살아남고 다음 부모로 선택될 수 있습니다. 이를 통해 과감하고 창의적인 **탐색(Exploration)**이 일어납니다.

### 🔵 저온 풀 (Cold Pool / Exploitation)
* **특징:** 온도 매개변수 $\beta$의 값을 높게 설정합니다 ($1.0$에 수렴).
* **효과:** 오직 평가 점수가 높은 엘리트 가설들만 살아남도록 통제합니다. 이를 통해 기존에 발견한 좋은 아이디어를 정교하게 파고드는 **심화(Exploitation)**가 일어납니다.

## 🔄 3. 정보 교환 메커니즘: 메트로폴리스-헤이스팅스 (MH) 스왑

두 풀이 완전히 독립적으로만 돌면 고온 풀은 쓰레기장으로 변하고, 저온 풀은 다양성 붕괴에 빠집니다. EvoDiverse는 이를 해결하기 위해 주기적으로 **Metropolis-Hastings(MH) 확률 공식**에 따라 두 풀의 가설을 교환(Swap)합니다.

* **상향 이동:** 고온 풀에서 우연히 발견된 품질 좋은 가설이 저온 풀의 엘리트 가설과 자리를 바꿉니다.
* **하향 이동:** 저온 풀에서 정체된 엘리트 가설이 고온 풀로 내려가 새로운 돌연변이(Mutation) 자극을 받습니다.
* **결과:** 저온 풀의 수렴 안정성을 깨뜨리지 않으면서도, 고온 풀의 참신한 아이디어가 지속적으로 공급되는 선순환 구조를 만듭니다.

## 🧪 4. 도메인별 초기 세팅 및 임베딩 활용법

EvoDiverse는 가설 자체를 공간에 매핑해서 통제하지 않고, **100% 원문 형태(자연어, 수식, 코드)**로 저장한 채 진화시킵니다. 임베딩 벡터는 오직 '사후 다양성 측정' 및 '적합도 평가 보조' 용도로만 사용했습니다.

| 도메인(Task) | 초기 가설 생성 방식 (Initial Population) | 사용한 임베딩/인코더 모델 |
| :--- | :--- | :--- |
| **분자 발견** *(Molecular)* | `ZINC-250K` 화합물 DB에서 120개의 무작위 분자를 샘플링하여 첫 풀 구축 | **Morgan Fingerprint** (분자 지문 벡터) |
| **방정식 발견** *(Equation)* | 변수 정의와 기초적인 수식 예시(선형식 등)를 **퓨샷 프롬프트**로 쥐여주고 생성 | **CodeBERT** (수식 구조의 의미론적 분석) |
| **알고리즘 발견** *(Algorithm)* | 인류가 기존에 구현해 놓은 **기성 솔루션 DB**에서 점수 기반 샘플링 | **TF-IDF** (단어 빈도수 기반 단순 임베딩) |

## ⚖️ 요약: EvoDiverse의 장점과 한계

* **장점:** 복잡한 기하학적 연산(Grid 분할, 고차원 밀도 추정)이 필요 없어 **연산 코스트가 매우 가볍고**, 수학적으로 안정적인 가설의 다양성을 보장합니다.
* **한계:** 공간의 거리 개념을 직접 활용해 탐색을 유도하는 눈이 없기 때문에, "어디가 아직 개척되지 않은 빈 땅인가?"를 정밀하게 저격해서 파고드는 **기하학적 타겟팅(Spatial Exploration)은 불가능한 구조**입니다.
