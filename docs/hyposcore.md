# 원자적 명제 기반 데이터 중심 가설 평가 방법론

## 1. 개요

본 문서는 복합 가설을 다음과 같은 절차로 평가하는 방법론을 제안한다:

1. 가설을 **원자적 명제(atomic propositions)**로 분해  
2. 각 명제를 데이터 기반으로 검증  
3. 검증 결과를 집계하여 **최종 가설 점수** 산출

이 방법은 다음 흐름을 통합한다:

- 원자 명제 기반 factuality 평가 (예: FActScore)
- coverage(포괄성)를 고려한 평가 (예: SAFE, VeriScore)
- claim decomposition 품질 평가 방법론

---

## 2. 전체 파이프라인

### Step 1: 가설 분해

가설 H 를 원자적 명제 집합으로 분해한다:

```
H → {a₁, a₂, ..., aₙ}
```

각 원자 명제는 다음을 만족해야 한다:

- **완전성 (Completeness)**: 핵심 정보 누락 없음  
- **정확성 (Correctness)**: 원문에 없는 정보 추가 없음  
- **독립성 (Independence)**: 의미적 중복 최소화  

---

### Step 2: 원자 명제 점수화

각 원자 명제 aᵢ 에 대해 데이터 기반 검증을 수행하고 점수 부여:

```
sᵢ ∈ [0, 1]
```

권장 스케일:

| 점수 | 의미 |
|------|------|
| 1.0  | 강하게 지지됨 |
| 0.7  | 부분적으로 지지됨 |
| 0.5  | 불확실 |
| 0.3  | 부분 반박 |
| 0.0  | 강하게 반박 |

---

### Step 3: 중요도 가중치 설정

각 명제에 가중치 wᵢ 부여:

```
Σwᵢ = 1  (i=1 ... n)
```

권장 기준:

| 유형        | 가중치     |
|-------------|-----------|
| 핵심 전제   | 0.25 ~ 0.40 |
| 주요 구성 요소 | 0.10 ~ 0.20 |
| 보조 정보   | ≤ 0.05    |

가중치 판단 기준:

- 해당 명제가 틀리면 가설이 무너지는가 (논리적 필수성)
- 해당 명제가 가설 설명에 얼마나 기여하는가 (설명 기여도)

---

## 3. 집계 지표

### 3.1 기본 점수 (가중 평균)

```
B(H) = Σ (wᵢ · sᵢ)
```

전체적인 지지 수준을 나타냄

---

### 3.2 커버리지 점수

임계값 τ 설정 (예: 0.7)

```
C(H) = Σ (wᵢ · 𝟙(sᵢ ≥ τ))
```
여기서 𝟙(sᵢ ≥ τ)는 sᵢ가 τ 이상일 때 1, 아니면 0

충분히 검증된 명제들이 전체에서 차지하는 비율

---

### 3.3 병목 점수

핵심 명제 집합을 K라고 할 때:

```
P(H) = min(sᵢ),  i ∈ K
```

가장 약한 핵심 전제를 반영

---

## 4. 최종 가설 점수

```
S(H) = λ·B(H) + μ·C(H) + ν·P(H)
```

조건:

```
λ + μ + ν = 1
```

권장 기본값:

- λ = 0.5 : 전체 평균
- μ = 0.3 : 커버리지
- ν = 0.2 : 병목 보호

---

## 5. 최종 판정 기준

| 점수 범위              | 해석           |
|------------------------|----------------|
| ≥ 0.8 & 핵심 ≥ 0.7     | 강하게 지지됨  |
| 0.6 ~ 0.8              | 조건부 지지    |
| 0.4 ~ 0.6              | 불확실         |
| 0.2 ~ 0.4              | 부분 반박      |
| < 0.2 또는 핵심 붕괴   | 반박됨         |

---

## 6. 예시

| 명제        | 가중치 | 점수 |
|-------------|--------|------|
| a₁ (핵심)   | 0.30   | 0.9  |
| a₂ (핵심)   | 0.25   | 0.8  |
| a₃          | 0.20   | 0.6  |
| a₄          | 0.15   | 0.9  |
| a₅          | 0.10   | 0.4  |

### 기본 점수
```
B(H) = 0.765
```

### 커버리지 (τ = 0.7)
```
C(H) = 0.70
```

### 병목
```
P(H) = 0.8
```

### 최종 점수
```
S(H) = 0.7525
```
→ **조건부 지지**

---

## 7. 핵심 인사이트

### 단순 평균의 한계

- 중요도 반영 불가
- 핵심 명제 붕괴를 반영 못함
- 부분 검증 상태를 과대평가

---

### 본 방법의 장점

- 해석 가능성 높음
- 복합 가설에 적합
- 다음 세 요소 균형 반영:
  - 정확성 (precision)
  - 포괄성 (coverage)
  - 구조적 안정성 (bottleneck)

---

## 8. 최소 구현 버전

초기 구현:

1. 가설을 3~7개로 분해  
2. 각 명제 점수 부여  
3. 간단한 가중치 설정  
4. B, C, P 계산  
5. 최종 점수 및 판정 출력  

---

## 9. 요약

이 방법론은 가설 평가를 다음 구조로 재정의한다:

> **가설 분해 → 원자 명제 검증 → 구조적 집계**

이를 통해 단순 평균이 아닌,  
**정확성 + 커버리지 + 핵심 안정성**을 동시에 반영하는 평가가 가능하다.
